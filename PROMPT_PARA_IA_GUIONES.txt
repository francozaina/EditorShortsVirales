REGLAS DE LAS 7 COLUMNAS DEL GUION (SEPARADAS POR '|'):

Formato obligatorio de cada línea debajo de `[GUION]`:

1. TIEMPO (Tramo real del video original):
   - Usa `MM:SS - MM:SS` cubriendo desde `00:00` hasta el final real del video (ejemplo: `00:00 - 00:05`, `00:05 - 00:10`, etc.).

2. EFECTO (Efecto visual de cámara y color sobre el video):
   Elige SOLO UNO por línea según la emoción del momento:
   - `zoom_impacto` -> Golpe de zoom rápido + micro-vibración (ideal para el gancho inicial o revelaciones fuertes).
   - `zoom_in`      -> Acercamiento progresivo y fluido hacia el objetivo señalado.
   - `zoom_out`     -> Alejamiento suave de cámara para mostrar contexto general.
   - `flash`        -> Destello luminoso de cámara al inicio del segmento.
   - `temblor`      -> Sacudida intensa de pantalla + impacto (ideal para golpes, explosiones o locuras).
   - `alerta_roja`  -> Viñeta roja pulsante de peligro, trampa, error o estafa.
   - `brillo_epico` -> Resplandor vibrante para victorias, desenlaces o finales épicos.
   - `blanco_negro` -> Desaturación dramática en blanco y negro para fails tristes o decepciones.
   - `ninguno`      -> Movimiento orgánico suave sin filtros adicionales.

3. SFX (Efecto de sonido sincronizado al inicio del bloque):
   Elige SOLO UNO de los 19 efectos disponibles en `sfx/` (o combina dos con `+`, ej. `whoosh+xp_Error`):
   - `crowd_shocked`  -> Multitud sorprendida (ideal para ganchos impactantes o revelaciones).
   - `whoosh`         -> Transición rápida de aire / cambio de acción.
   - `riser_suction`  -> Subida de tensión absorbente (ideal justo antes del giro o broma).
   - `ding`           -> Campana de acierto, idea clave o detalle oculto.
   - `good_idea`      -> Sonido de idea brillante o plan maestro.
   - `cash_ting`      -> Caja registradora / dinero / premio / valor.
   - `punch`          -> Golpe seco / impacto físico / broma pesada.
   - `boxing_bell`    -> Campana de boxeo (inicio de reto o duelo).
   - `camera_flash`   -> Flash de fotografía (combina con `flash`).
   - `camera_shooter` -> Disparo de cámara / evidencia captada.
   - `cartoon_laugh`  -> Risa caricaturesca para momentos graciosos o burlas.
   - `kids_yeyy`      -> Grito de celebración "¡Yey!" para finales felices.
   - `party_horn`     -> Corneta de fiesta para celebrar un triunfo o final feliz.
   - `awww`           -> Sonido de ternura o lástima cómica.
   - `error`          -> Buzzer corto de fallo o equivocación.
   - `xp_Error`       -> Error de Windows XP para confusión mental o bug.
   - `fart`           -> Sonido cómico para fails ridículos.
   - `click`          -> Clic seco de botón.
   - `pop`            -> Pop de burbuja.
   - `ninguno`        -> Sin efecto de sonido adicional.

4. EMOJI (PNG animado con rebote elástico en pantalla):

5. FLECHA (Flecha roja grande `flecha.png` con seguimiento inteligente de objetivos):

   - La flecha es el señalador principal: úsala en la mayoría de los bloques donde haya algo que señalar (no hace falta en todos; puedes dejar alguno en `ninguna`).
   - Aparece de forma ágil y breve (~1.8 segundos) para captar la atención inmediatamente y luego desaparecer sin tapar el video.

6. CIRCULO (Círculo rojo grande `circulo_rojo.png` con seguimiento inteligente de objetivos):
   Rodea y persigue al objetivo en pantalla:
   - `centro`, `izquierda`, `derecha`, `arriba`, `abajo`, `auto`, `X,Y` (ej. `50,50`) o `ninguno`.
   - Opcional: agrega `:chico`, `:medio` o `:grande` (ejemplo: `izquierda:grande`).
   - ⚠️ **LÍMITE ESTRICTO: usa el círculo en 1 o 2 bloques COMO MÁXIMO en todo el guion**, reservado para los momentos más importantes (el detalle clave o el desenlace). En todos los demás bloques escribe `ninguno` en CIRCULO y usa solo la FLECHA. ¡NUNCA pongas flecha + círculo en todos los bloques!
   - Al igual que la flecha, dura poco tiempo (~1.8 segundos) y se desvanece suavemente para no saturar la pantalla.

7. TEXTO (Narración de Voz IA + Subtítulos Luminosos):
